# Intern Registration App

A full-stack web application to manage intern registrations. This project demonstrates RESTful API principles including GET, POST, PUT, and DELETE.

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)

## ✨ Features
- **Create:** Register new interns (POST)
- **Read:** View a list of all registered interns (GET)
- **Update:** Edit existing intern details (PUT)
- **Delete:** Remove interns from the system (DELETE)

## 🚀 How to Run
1. Clone this repository.
2. Open a terminal in the `backend` folder and run `npm install` then `node server.js`.
3. Open the `frontend/index.html` file in your browser.
